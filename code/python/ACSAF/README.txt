DLR-ACSAF FTP-server: acsaf.eoc.dlr.de

This DLR-ACSAF FTP-server contains the GOME-2 trace gas column data products (Level 2 and Level 3) 
provided in the framework of the Satellite Application Facility on Atmospheric Composition Monitoring (AC SAF).

GOME-2 products from Metop-A are located in the directory: 'gome2a/'
Time period: 04.01.2007 - 15.11.2021(GOME-2 Level 2 Data Processor version: GDP 4.8)

GOME-2 products from Metop-B are located in the directory: 'gome2b/'
Time period: 15.07.2013 onwards (GOME-2 Level 2 Data Processor version: GDP 4.8)

GOME-2 products from Metop-C are located in the directory: 'gome2c/'
Time period: 01.02.2019 onwards (GOME-2 Level 2 Data Processor version: GDP 4.9)

Near real time (NRT) level 2 products (for the last 3 months) are located in the sub-directory: 'near_real_time/' 
Off-line and reprocessed level 2 products (since beginning of mission) are located in the sub-directory: 'offline/'
Data records are located in the sub-directory: 'data_records/'
Level 3 products are located in the sub-directory: 'level3/'


GOME-2 level 2 products:

Near real time (NRT)
- Total ozone column (O3)
- Total and tropospheric NO2 column
- SO2 column
- Tropospheric formaldehyde column (HCHO)

Off-line and reprocessed products
- Total ozone column (O3)
- Total and tropospheric NO2 column
- SO2 column
- Total BrO column
- Tropospheric formaldehyde column (HCHO)
- Total water vapour column (H2O)
- OClO column (reprocessed dataset for MetOp-A and -B only; period: 04.01.2007 - 16.11.2016) 

Data records (Metop-A and -B only; period: 04.01.2007 - 30.06.2020)
- Tropospheric BrO column 
- Tropospheric glyoxal column (CHOCHO) 


GOME-2 level 3 products:

Off-line daily and monthly mean (gridded) products
- Total ozone column (O3)
- Total and tropospheric NO2 column
- SO2 column
- Total BrO column
- Tropospheric formaldehyde column (HCHO)
- Total water vapour column (H2O)
- Tropical tropospheric ozone column (O3tropo), monthly only


The GOME-2 data files on acsaf.eoc.dlr.de can be downloaded via Anonymous FTP using a FTP-client 
(command line FTP, FileZilla, WinSCP, etc.)

Detailed information about the GOME-2 trace gas columns products, including Product User Manual, ATBD and 
Scientific Validation Reports can be found in the sub-directory 'documents/' and at:
http://acsaf.org

Daily quick-look images of the GOME-2 trace gas column products can be found at:
https://atmos.eoc.dlr.de/app/missions/gome2

The AC SAF Data Use Policy can be found at: 
http://acsaf.org/data_policy.php
